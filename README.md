# 英二 · 词句

考研英语二单词与长难句的静态学习站。手机优先，打开即用。

网址：https://cherry9099-c.github.io/ENG2/

## 它有什么

- **刷单词**：按卷子过词，三档打分（不认识 / 不熟 / 认识），进度存在浏览器本地
- **完整词表**：全部词按考点 / 核心 / 大纲 / 基础四档浏览，点开看音标、文中形态和真题原句
- **句式**：每篇文章的段落骨架（逐段作用与主旨）+ 长难句逐句拆解（主干 / 成分 / 括号化 / 翻译 / 考点）
- **阅读器**：读真题原文，点词查义；也能粘贴自己的文章
- **统计**：各卷掌握程度、学习热力图、最容易忘的词

3 套真题：2021 英语二、2020 英语二、2007 英语一（旧）。

进度全部存在你自己的浏览器里，不上传任何服务器。换设备时用「统计 → ⋯ → 导出备份」。

## 手机上装成 App

用 Safari（**不要用微信内置浏览器**）打开网址 →
底部「分享」→「添加到主屏幕」。图标和全屏都正常。
